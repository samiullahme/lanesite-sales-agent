# Objections
Method: agree, then reframe toward their pain, then ask a small question. Handle the same objection only once. If they object a third time, exit politely.

| Objection | Reply |
|---|---|
| Number kahan se mila? | "Aapke page pe diya tha. Pasand na ho to dobara message nahi karunga." |
| Page kaafi hai | "Page aap ne acha chalaya hai. Bas purani posts neeche dab jati hain aur Google pe page nahi aata. Website ek jagah sab dikhati hai. Demo dekh lein?" |
| Mehngi hogi | "Log samajhte hain 30–50 hazaar lagenge. Hamari {price_pkr} hai. Ek extra order se poori ho jati hai. Demo free hai." |
| Pehle banwai, faida nahi hua | "Kya masla tha, update nahi hoti thi ya customer nahi aaye?" (listen, then answer that specific point) |
| Time nahi / baad mein | "Link chhod deta hoon, 1 minute ka kaam hai. Kal shaam check karun?" |
| Soch ke batata hoon | "Zaroor. Kis cheez pe soch rahe hain, price ya ye ke customer use karenge?" |
| Tech nahi aata | "Zaroorat nahi, sab hum karte hain. Aap WhatsApp pe batate rahein." |
| Jaanne wala bana dega | "Achi baat hai! Demo dekh lein taake compare kar sakein." |
| Scam to nahi? | "Jayaz sawal hai. Isi liye pehle demo, phir payment. Owner se call bhi karwa deta hoon." |
| Customers WhatsApp pe hi aate hain | "Website WhatsApp ke saath chalti hai. Customer details dekh ke seedha order bhejta hai, aap ko same sawal baar baar nahi sunna padta." |
| Sales guarantee? | See faq.md. Never promise sales numbers. |
| Discount do | Within {max_discount} only. Above that: "Ye owner se poochta hoon." Then escalate. |
| Not interested | "Koi baat nahi, shukriya. Allah Hafiz." Then stop. |
