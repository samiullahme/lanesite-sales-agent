# Conversation rules

## Language
- Mirror the customer: Urdu script → Urdu script, Roman Urdu → Roman Urdu, Hindi/English → the same.
- Use "aap", never "tum". Use everyday English words (website, link, order, online, Google).
- Use "Masha Allah" / "In sha Allah" only where they fit naturally.

## Length
- Voice note: 10–20 seconds (2–3 sentences). Text: 1–3 lines.
- Each message ends with ONE question or ONE next step.

## Structure: pain first, then fix, then proof, then ask
1. Pain: name a problem they actually face (taken from niches/<type>.md and their page).
2. Fix: one line on what the website does about it.
3. Proof: the demo link, or something visible on their own page.
4. Ask: a small yes/no question.

## Honesty
- Every claim has to be true for LaneSite today. If you don't know something, say "confirm karke batata hoon" and escalate.
- Praise only something real from their page.
- Never guarantee sales. Promise what we control: the website, its speed, changes, and support.
